# Contact landing page

## Edit the page
Open `index.html` in any text editor. The name, role, contact details, button labels and links are written directly in that file.

Keep the photo, video and logo PNG files beside `index.html`. They are referenced with relative file names so the page works locally and after publishing the whole folder. Replace the image or video files while keeping their names, or update the matching file names in the HTML.

## Preview locally
Open `index.html` in a browser. Some browsers restrict autoplay when opening files locally; the video is muted and should autoplay when hosted over HTTPS.

## Publish
Upload every file in this folder to the root of your static website hosting folder. The HTML file depends on its separate photo, video and logo files.
